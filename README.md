# 宝宝成长相册 Demo 1.5 Pro

一个面向手机端的本地宝宝成长相册。它可以记录宝宝资料、成长故事和照片，也支持自定义背景、音乐、插画与章节名称。

项目由两部分组成：

- `frontend/`：网页展示和编辑界面。
- `backend/`：FastAPI 后端，负责保存资料和媒体文件。

> 使用网站时，前端和后端必须同时运行。数据默认保存在运行后端的电脑中，不会自动上传到云端。

## 一、使用前准备

系统建议使用 Windows 10 或 Windows 11，并提前安装：

- Node.js 20 或更高版本
- Python 3.11 或更高版本
- Git（只有通过 Git 下载或参与开发时需要）

打开任意终端后，可以检查安装情况：

```powershell
node --version
npm.cmd --version
python --version
git --version
```

如果某条命令提示无法识别，请先安装对应软件并重新打开终端。

### 获取项目文件

普通用户可以在代码仓库页面选择“下载 ZIP”，下载完成后先解压，再打开解压得到的项目文件夹。

熟悉 Git 的用户也可以先在准备存放项目的位置打开终端，然后执行：

```powershell
git clone <仓库链接>
```

将 `<仓库链接>` 替换为仓库页面提供的 HTTPS 地址。克隆完成后，在资源管理器中打开新生成的项目文件夹。

## 二、如何在正确位置打开终端

本项目不要求用户手动输入电脑中的完整文件地址。

### 方法一：从资源管理器打开 PowerShell（推荐）

1. 在 Windows 资源管理器中打开项目文件夹。
2. 点击窗口顶部的地址栏。
3. 输入 `powershell`。
4. 按回车，即可在当前文件夹打开终端。

启动项目需要两个终端：

- 后端终端：先进入项目中的 `backend` 文件夹，再按上面的方法打开 PowerShell。
- 前端终端：停留在项目最外层文件夹，再按上面的方法打开 PowerShell。

### 方法二：使用右键菜单

在目标文件夹空白处按住 `Shift` 并点击鼠标右键，然后选择“在此处打开 PowerShell 窗口”或“在终端中打开”。

## 三、第一次使用

以下操作只需要执行一次。

### 1. 安装前端依赖

在项目最外层文件夹打开终端，执行：

```powershell
npm.cmd install
```

### 2. 安装后端依赖

进入 `backend` 文件夹并在其中打开终端，依次执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 3. 设置编辑密码

继续在 `backend` 文件夹的终端中执行：

```powershell
Copy-Item .env.example .env
notepad .env
```

在打开的文件中设置自己的编辑密码：

```env
BABY_ALBUM_EDITOR_PIN=请替换成自己的密码
```

建议使用 6～12 位数字或字母。保存后关闭记事本。

`.env` 是本机私密配置，已经被 Git 忽略，不会提交到 GitHub。不要把真实密码写进 `.env.example`。

## 四、每次如何启动

建议先启动后端，再启动前端。

### 1. 启动后端

进入 `backend` 文件夹，在此处打开第一个终端，然后执行：

```powershell
.\.venv\Scripts\python.exe run.py
```

看到 Uvicorn 已启动的提示后，不要关闭这个终端。

### 2. 启动前端

返回项目最外层文件夹，在此处打开第二个终端，然后执行：

```powershell
npm.cmd run dev
```

终端会显示：

- `Local`：当前电脑访问使用的网址。
- `Network`：同一局域网中的手机或其他设备使用的网址。

复制终端实际显示的网址到浏览器中打开即可，不需要手动猜测端口或电脑地址。

### 3. 停止项目

在前端和后端两个终端中分别按：

```text
Ctrl + C
```

## 五、手机通过家庭 Wi-Fi 使用

1. 让手机和电脑连接同一个可信的家庭 Wi-Fi。
2. 保持前端和后端两个终端正常运行。
3. 在手机浏览器中打开前端终端显示的 `Network` 网址。
4. Windows 防火墙首次询问时，只允许“专用网络”，不要允许公共网络。

手机查看相册不需要密码。进入“宝宝档案”“成长记录”或“个性化”时，需要输入 `backend/.env` 中配置的编辑密码。

同一时间只允许一台设备编辑。如果另一台设备正在编辑，可以输入密码并选择“强制接管编辑”。

手机端支持资料、故事、照片和个性化内容的日常修改；完整备份、恢复演示数据和存储设置只在电脑端显示。

## 六、主要功能

- 六个成长章节和章节时间轴
- 宝宝资料、成长故事的新增与修改，以及故事封面直接上传
- 照片上传、压缩、排序、删除和滑动浏览
- 每篇故事可直接上传一个 MP4 或 WebM 视频，并支持替换、删除和自定义封面
- 自定义网页背景、透明度、背景音乐和插画
- 自定义章节名称和章节插画
- 自动保存资料与成长故事
- 手动保存个性化设置
- 可拖动的音乐悬浮按钮
- `.baby-album.zip` 完整备份与恢复
- 家庭局域网免密查看、密码编辑和单设备编辑保护
- 展示页面定时同步其他设备保存的新内容

## 七、数据保存与完整备份

用户数据保存在后端的 `data` 文件夹中：

```text
backend/data/app.db
backend/data/media/
```

- `app.db` 保存宝宝资料、故事和媒体索引。
- `media/` 保存上传的照片、视频、背景、插画和音乐。
- 不要随意删除 `backend/data/`。
- `backend/data/` 已被 Git 忽略，不会上传到 GitHub。

电脑端可以在“成长记录 → 数据管理”中：

- 导出完整备份：生成 `.baby-album.zip` 文件。
- 导入完整备份：恢复资料以及后端已经保存的媒体文件。

视频也会进入完整备份。由于视频体积通常远大于照片，包含视频的 ZIP 文件可能明显变大，请为电脑硬盘和备份位置预留足够空间。

### 视频上传说明

- 每篇故事最多保存一个视频。
- 支持 MP4、WebM，默认单个文件最大 200MB。
- 推荐使用兼容性较好的 MP4（H.264 视频编码、AAC 音频编码）。
- 项目不会自动转码；如果浏览器无法播放，请先用其他软件转换为兼容格式。
- 视频只有在用户点击播放后才开始加载，不会在打开故事列表时自动下载。
- 可在 `backend/.env` 中用 `BABY_ALBUM_MAX_VIDEO_MB` 调整上限，修改后需重启后端。

更换电脑、重装系统或清理项目之前，请先导出完整备份。

## 八、内置图片素材

网站自带的图片位于：

```text
frontend/public/images/
```

代码中应使用网站相对路径，例如：

```text
/images/cover_baby.svg
```

不要把某台电脑的完整本地地址写进前端代码，否则项目复制到其他电脑后会找不到图片。

## 九、常见问题

### 终端提示找不到 `package.json`

说明当前终端没有打开在项目最外层文件夹。关闭终端，在资源管理器中重新打开项目最外层文件夹，然后在地址栏输入 `powershell` 并回车。

### 找不到 `.venv\Scripts\python.exe`

说明后端虚拟环境尚未创建。进入 `backend` 文件夹打开终端，重新执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### PowerShell 不允许执行 `npm`

在 Windows 上使用：

```powershell
npm.cmd install
npm.cmd run dev
```

### 页面提示“后端未启动”

检查后端终端是否仍在运行。如果已经关闭，请进入 `backend` 文件夹重新启动后端。

### 修改密码后仍提示密码错误

修改 `.env` 后必须停止并重新启动后端，新密码才会生效。

### 手机无法打开网页

- 确认手机和电脑连接同一个 Wi-Fi。
- 使用前端终端显示的 `Network` 网址，不要使用 `Local` 网址。
- 确认 Windows 当前网络类型为“专用网络”。
- 允许 Node.js 和 Python 通过专用网络防火墙。
- 某些访客 Wi-Fi 会隔离不同设备，需要换用正常家庭网络。

### 手机能打开网页但无法保存或上传

- 确认后端终端仍在运行。
- 确认编辑密码正确。
- 确认没有另一台设备正在占用编辑状态。
- 如果旧设备已离开，可等待编辑占用自动释放或选择强制接管。

### 视频无法上传或播放

- 确认文件扩展名和实际格式都是 MP4 或 WebM，且没有超过后端设置的大小上限。
- 某些 MP4 内部使用 HEVC 等浏览器不兼容编码；请转换为 H.264 + AAC 后重试。
- 手机播放依赖电脑端 FastAPI，电脑关机、后端停止或手机离开同一 Wi-Fi 后无法播放。

## 十、项目结构

```text
项目文件夹/
├─ frontend/                 React 前端
│  ├─ public/images/         网站内置图片
│  ├─ src/                   页面、组件和前端逻辑
│  └─ tests/e2e/             浏览器自动化测试
├─ backend/                  FastAPI 后端
│  ├─ app/                   API、认证、数据库和媒体处理
│  ├─ data/                  本机私人相册数据
│  ├─ tests/                 后端测试
│  ├─ requirements.txt       Python 依赖
│  └─ run.py                 后端启动入口
├─ scripts/                  测试辅助脚本
├─ docs/                     项目规划与技术文档
├─ package.json              前端命令入口
└─ README.md                 使用说明
```

## 十一、开发与检查命令

以下命令在项目最外层文件夹的终端中执行：

```powershell
# 启动前端
npm.cmd run dev

# 检查代码
npm.cmd run lint

# 生产构建
npm.cmd run build

# 浏览器自动化测试
npm.cmd run test:e2e

# 后端测试
.\backend\.venv\Scripts\python.exe -m pytest backend\tests -q
```

## 十二、当前版本范围

- 前端：React、TypeScript、Tailwind CSS、TanStack Start、Vite
- 后端：FastAPI、SQLite、本机媒体目录
- 支持：本机运行和可信家庭局域网访问
- 暂不支持：云端存储、账号注册、HTTPS、公开分享链接和付费系统

这是一个本地家庭相册版本。运行后端的电脑关机，或者前端、后端终端停止后，其他设备将无法继续访问。
