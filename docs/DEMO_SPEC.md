# Demo 页面规格

## 1. Demo 目标

用一个虚构宝宝的 0—3 岁成长内容，完成适合手机浏览的绘本式纪念网页。重点验证视觉氛围、章节浏览、故事阅读和媒体查看。

## 2. 页面流程

```text
封面
  → 成长章节目录
    → 章节故事列表
      → 故事详情
        → 照片/视频全屏浏览
```

返回路径必须与进入路径一致，关闭媒体后回到原故事，关闭故事后回到原章节。

## 3. 核心视图

### A. 封面与目录

- 宝宝展示名、出生日期、欢迎语
- 主视觉插画
- 进入时光轴按钮
- 6 个成长章节入口

### B. 章节故事列表

- 章节标题、年龄范围、章节插画
- 1—2 个故事卡片
- 故事卡片显示日期、标题、封面和摘要
- 返回章节目录

### C. 故事详情

- 完整标题、日期和故事文字
- 1 张主图及若干缩略图
- 可选视频入口
- 下一篇故事
- 返回当前章节

### D. 媒体浏览器

- 全屏查看图片或播放视频
- 左右切换
- 当前序号/总数
- 明确关闭按钮

## 4. Demo 内容

- 1 个虚构宝宝
- 6 个章节
- 6—8 个故事
- 每个故事 1—6 张图片
- 全站最多 1—3 个短视频或视频占位

章节暂定：诞生记忆、牙牙学语、蹒跚学步、探索世界、小小冒险家、继续长大。

## 5. 视觉方向

- 风格：温柔、自然、带手作感的儿童绘本
- 主配色：奶油纸张色＋低饱和章节色
- 字体：中文正文首先保证可读，手写字体只用于短标题或便签
- 形状：圆角卡片、不规则纸张、轻阴影、少量虚线
- 动画：轻柔淡入和位移，不使用高频或复杂动画
- 桌面端：保持手机绘本宽度居中，不把内容无限拉宽

现有插画可作为第一轮设计素材，但最终布局不受当前页面限制。

## 6. 素材规则

- 优先复用 `public/images` 和现有素材目录中的插画。
- 示例宝宝照片使用虚构、已授权或许可清晰的免费素材。
- 网络素材需保存来源和使用许可。
- 如果需要用户补充素材，应一次说明：用途、数量、比例、建议尺寸和格式。
- 图片缺失时必须显示稳定占位，不能造成页面崩溃。

第一轮暂不向用户索取新素材；完成版式后再判断是否缺少背景纹理、封面主图或章节装饰。

## 7. 响应式与交互

- 重点测试宽度：320、375、390、430 和 768px。
- 正文不得小于 14px，辅助信息不得低于 11px。
- 主要点击区域建议至少 44×44px。
- 弹层打开时锁定背景滚动，关闭后恢复。
- 支持键盘 Escape 关闭媒体，桌面端支持方向键切换。
- 所有图片提供替代文本或明确的装饰属性。

## 8. Demo 验收

- 用户能连续完成“封面→章节→故事→媒体→返回”。
- 6 个章节均可进入，空内容不会导致报错。
- 图片和视频占位都能正常显示。
- 手机端无横向溢出、遮挡或无法关闭的弹层。
- 页面控制台无已知运行时错误。
- 文案、宝宝信息和故事数据不散落在主要 UI 组件中。
