# `new-lovable` 参考审计

## 1. 参考原则

`new-lovable` 只作为信息架构和交互密度参考。Demo 1.5 继续以 Demo 1.0 的绘本相册、章节目录和故事弹层为产品原型，不复制参考项目的代码、页面结构或视觉方案。

## 2. 可以借鉴

- 首页提供更清晰的年龄范围、引导语和进入入口；
- 导航区分首页、时光轴、相册和家书等内容入口；
- 时间段筛选帮助用户快速定位成长阶段；
- 时间轴卡片增加日期、标签、照片数量和内容状态；
- 相册提供聚合查看入口；
- 故事和家书可以承载比卡片摘要更完整的内容；
- 搜索、筛选、展开详情等交互提升内容较多时的可用性。

## 3. 不采用

- WebGL 流体背景；
- 3D 鼠标倾斜卡片；
- 粒子系统和高频视觉特效；
- 桌面端优先的大幅横向时间轴；
- 将所有照片、视频和文章一次性聚合加载；
- 直接复制其组件、文案、数据或视觉令牌。

## 4. Demo 1.5 的转化方式

| 参考项目能力   | Demo 1.5 转化                           |
| -------------- | --------------------------------------- |
| 多标签导航     | 保留绘本首页，增加章节、相册和编辑入口  |
| 时间段筛选     | 使用六个成长章节作为筛选器              |
| 丰富时间轴卡片 | 增加标签、媒体数量和故事状态            |
| 照片墙         | 增加按章节聚合的轻量相册视图            |
| 家书文章       | 将故事正文扩展为可选长文/家书类型       |
| 复杂背景动画   | 改为主题插画微动和时间线绘制            |
| 全局搜索       | 内容达到一定数量后加入本地标题/标签搜索 |

## 5. 判断标准

任何参考内容只有同时满足以下条件才允许进入 Demo 1.5：

1. 能提升宝妈用户的理解或操作效率；
2. 不破坏 Demo 1.0 的绘本气质；
3. 不显著增加素材加载和手机性能压力；
4. 能由主题配置复用，而不是为单一页面写死；
5. 对轻定制交付或未来商业验证有直接价值。
