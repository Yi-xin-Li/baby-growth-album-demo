# 宝宝成长网站 Demo 1.5 更新计划

## 1. 版本目标

Demo 1.5 在 Demo 1.0 的绘本式成长相册基础上，升级为可配置、可预览、可导出的轻定制版本。

核心价值：

- 用插画主题形成视觉辨识度，而不是依赖复杂特效；
- 用一套数据和组件承载三套主题；
- 让非技术用户可以修改宝宝资料、故事、主题和插画；
- 为未来账号、云存储和付费能力预留接口，但本阶段不接云端。

## 2. 产品边界

### 本版本完成

- 森林成长记、奶油手账本、星空冒险记三套主题；
- 主题颜色、字体、纹理、插画槽位和轻动画配置；
- 更丰富的首页信息、章节筛选、相册入口和故事标签；
- 时间轴绘制、节点进入和主题装饰动画；
- 本地编辑后台与实时预览；
- IndexedDB 草稿保存；
- 图片选择、校验、压缩和缩略图/预览图/原图三级资源；
- JSON 导入导出与完整交付包设计；
- 移动端和关键流程自动化测试。

### 本版本不完成

- 账号登录、在线支付、云数据库和云对象存储；
- 多家庭权限隔离、在线协作和独立客户域名；
- 任意拖拽式页面编辑器；
- 在线视频转码和无限素材容量；
- AI 文案接口。

## 3. 页面结构

```text
/                     相册展示与章节目录
/chapter/:chapterId   章节时间轴
/editor               本地编辑后台
/preview              编辑结果预览
```

故事详情和媒体浏览器第一阶段继续使用弹层，数据结构为未来独立路由保留 ID。

## 4. 主题架构

主题包负责：

```text
色彩令牌
字体组合
背景纹理
封面插画
章节插画
时间轴造型
卡片和便签装饰
轻动画参数
允许替换的插画槽位
```

主题切换不得复制页面代码。主题差异通过 CSS 变量、主题配置和少量布局变体完成。

## 5. 媒体策略

```text
thumbnail  用于时间轴和卡片
preview    用于故事详情
original   仅在全屏查看时加载
```

固定插画通过项目内资源导入；客户媒体只保存相对路径或浏览器对象 ID，禁止保存电脑绝对路径。

## 6. 实施阶段

1. 参考项目审计与范围确认；
2. 主题数据模型、主题包和切换基础；
3. 展示端信息与交互增强；
4. 本地编辑后台和实时预览；
5. 媒体处理、草稿保存和导入导出；
6. 自动化测试与移动端验收。

每阶段必须保持 `lint` 和 `build` 可通过，并建立独立 Git 提交。

## 7. 完成标准

- 三套主题在相同内容数据下均可完整浏览；
- 用户无需修改代码即可编辑主要资料、故事和插画；
- 页面只按需加载当前需要的媒体；
- 导出的项目在另一台电脑上不会因绝对路径丢失图片；
- 320—430px 手机宽度能够完成全部核心流程；
- Demo 1.0 标签与 `main` 分支保持不变。
